# Skill Challenge Scales

## Установка

В Foundry: Add-on Modules → Install Module → в поле **Manifest URL** вставьте:

 https://github.com/Logan-292/skill-challenge-scales/releases/latest/download/module.json

Требования: Foundry VTT v14, система D&D 5e (dnd5e 4.0.0+).


Модуль для Foundry VTT v14 (система D&D 5e): наглядные весы для испытаний навыков.
Алмазы\Зеленые камни на левой чаше — успехи, черепа\серые камни на правой — провалы.

## Установка

1. Скопируйте папку `skill-challenge-scales` в `Data/modules/`.
2. Перезапустите Foundry, включите модуль в настройках мира.

## Для мастера

- Показать/скрыть весы в текущей сцене: кнопка с весами в панели токенов (слева) или `Alt+K`.

- Шестерёнка на панели открывает управление:
  - название, число успехов для победы и число провалов до поражения (хранится отдельно для каждой сцены);
  - ручная правка счёта и сброс;
  - выбор навыка или характеристики, КС, опция «Скрыть КС» и кнопка «Отправить в чат».
- В чат уходит карточка с кнопкой «Бросить». Игрок выбирает токен (или использует назначенного персонажа) и бросает.
  Результат автоматически попадает на весы и в журнал. Один персонаж бросает каждую проверку один раз.
- Когда набрано нужное число успехов или провалов, в чат уходит итоговое сообщение.

## Настройки

- «Показывать игрокам результаты бросков»: если выключено, игроки видят в журнале только ✔/✘.

## Заметки

## Скины

Весы собираются из слоёв-картинок, внешний вид задаётся скином (папка со `skin.json` и PNG/WebP).
Подробности: `skins/README.txt`. Готовая папка для вашего скина: `skins/my-scales/`.
Выбрать скин: шестерёнка на панели весов, поле «Скин». Порядок слоёв снизу вверх:
background, предметы, base, чаши, beam, hub (ось), front. Чаши лежат под коромыслом и осью.
